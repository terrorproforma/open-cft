# Axisymmetric L1a Workstream Report

## Delivered milestone

The workstream now has a genuine two-dimensional axisymmetric magnetostatic
solver producing node-centred `psi`, `B_r`, and `B_z` maps for multiple
annular/axial azimuthal-current bands. It has a dependency-free Python
reference and real NVIDIA Warp 1.14 binary64 kernels running on Warp CPU and
RTX 5090 `cuda:0`.

The claim is intentionally limited to **L1a**: linear, constant-permeability,
equivalent-current, finite-box, structured-grid FDM. It is neither a final
permanent-magnet/nonlinear-iron FEM model nor a plasma solve.

## Formulation

With `psi=r A_phi`, the implemented positive equation is

`-div[(1/r) grad psi] = mu J_phi`,

equivalent to

`psi_rr-(1/r)psi_r+psi_zz = -mu r J_phi`.

Fields are `B_r=-(1/r)psi_z` and `B_z=(1/r)psi_r`. Regularity requires
`psi=a(z)r²+O(r⁴)`, giving `B_r(0,z)=0` and `B_z(0,z)=2a(z)`. Full sign,
unit, boundary, source, and discretization derivations are in
`axisymmetric-formulation.md` and the machine-readable equation ledger.

## Hypothetical design outputs

All three use a `0.14 m x [-0.16,0.16] m` domain with 64x128 intervals.
Published JSON is generated by the Python reference and downsampled to a
dashboard-ready 17x33 map while retaining full centreline and wall profiles.

1. `hypothetical-compact-mirror`: two `15 mm` radial by `30 mm` axial bands
   at radii `42-57 mm`, both `+2200 A-turn`. It reaches
   `|B|max=0.0449600146 T`, has no detected interior axis null, converges in
   279 iterations, and has true relative residual `9.6017380e-11`.
2. `hypothetical-opposed-cusp`: two `20 mm` by `45 mm` bands at radii
   `47-67 mm`, `+2600/-2600 A-turn`. It reaches
   `|B|max=0.0383620584 T`, has the expected axis null at `z=-1.21e-17 m`
   (roundoff-equivalent to zero), converges in 259 iterations, and has relative
   residual `8.9723386e-11`.
3. `hypothetical-thick-outer-triplet`: outer `30 mm` by `50 mm` bands at
   `60-90 mm`, each `+3200 A-turn`, plus an inner `20 mm` by `50 mm`
   `-1800 A-turn` band. It reaches `|B|max=0.0363920515 T` and has
   interpolated axis nulls at `z=+-0.0293200 m`. It converges in 285
   iterations with relative residual `9.6699986e-11`.

The zero global `|B|min` reported in each artifact occurs at finite-box corner
boundary samples and is not a physical null claim. Topology now distinguishes
degenerate fields, sign-changing/isolated axis nulls, near-zero plateaus, and
outer-boundary minima. Maximum flux-reconstruction identity defect across
these outputs is `2.78e-15 T/m`; this is not independent field validation.
Dual-cell source transfer conserves requested signed
ampere-turns to binary64 summation error: at worst `1.28e-11 A-turn` per band
and `2.73e-11 A-turn` per design. Maximum reported centroid lumping error is
`1.31e-5 m`; maximum overlap-area roundoff is `6.08e-18 m²`.

## Runtime observations

These are one-shot, transfer-inclusive observations under uncontrolled
interactive load and are **diagnostic only**, not benchmarks. The final
source-conserving Python reference runs observed were approximately
`0.95-1.18 s/design`. Final cached-kernel Warp CPU observations were
`0.05-0.23 s/design`; RTX 5090 observations were `0.11-0.17 s/design`.
Setup, synchronization, transfers, Python final-residual reapplication, and
artifact construction are included inconsistently, so no speedup claim should
be inferred.

## Gates before “L1 production”

The following are mandatory before removing the L1a qualifier:

- correctly derive and verify equivalent magnetization/surface-current
  mapping for actual permanent-magnet geometry and grade;
- represent material interfaces and sourced permeability;
- add nonlinear B-H iron with robust nonlinear convergence;
- verify open/infinite boundary treatment and domain truncation independence;
- perform geometry/quantity-of-interest mesh convergence;
- match FEMM full profiles, not just selected extrema;
- preferably cross-check with an independent MFEM formulation or revolved 3D
  solve;
- compare against measured field maps with uncertainty.
