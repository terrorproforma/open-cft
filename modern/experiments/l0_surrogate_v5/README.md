# L0 surrogate v5

V5 is a new blind L0 software-emulation experiment. It uses a 16,384-row
digit-scrambled continuous input design and never uses a v3/v4 calibration or
assessment coordinate. V4 is development evidence only.

The frozen roles are training candidate, interval-method selection, final
conformal calibration, and single-use assessment. Method selection compares
absolute-residual, raw-GP-SD, and input-distance scaling with symmetric and
signed/asymmetric forms. The final quantile is estimated only on the separate
calibration groups.

Execution is permitted once from a clean detached worktree at the pushed
preregistration commit. Git identity, the complete imported dependency
subtrees, and an atomic retained exclusive lock are checked before any new
physics label is evaluated.

This experiment measures deterministic L0 software-emulation accuracy. It
makes no physical-accuracy claim.
