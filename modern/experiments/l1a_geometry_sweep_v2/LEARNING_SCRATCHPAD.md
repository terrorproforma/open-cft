# Learning scratchpad — L1a geometry sweep v2

## Established before execution

- v1 is retained as numerically passing but protocol-unproven development
  evidence; v2 does not import v1 experiment code or results.
- The sealed protocol is the sole authority for 96 sample identities, seven
  terminal gates, five representative roles, objective directions and replay
  tolerances.
- Zero case failures is mandatory in addition to all seven metric gates.
- Five roles may coalesce to fewer unique cases. Unique representative
  artifacts exactly equal the set of role-selected case IDs; no case is added
  to reach an arbitrary artifact count.
- CUDA field values are not expected or claimed to replay bitwise. Sampling,
  geometry, source and configuration identities are hash-exact.
- Full and downsampled representative fields are derived from cached primary
  solves. The experiment does not rerun selected geometries.

- Seven independently recomputable gate outcomes and zero-failure condition.
- Nondominated set, five role mappings and unique artifact count.
- GPU, Warp, CUDA toolkit/runtime, driver, scalar and code revision metadata.
- Strict sidecar, payload and artifact reload evidence.
