# L0 surrogate v7 learning scratchpad

- Equal group mass is not enough if the finite-sample rank still uses pooled
  row count.
- Simultaneous within-group coverage has a clear exchangeability statement:
  reduce each independent group to one maximum nonconformity score.
- Asymmetric simultaneous intervals need two exact one-sided group bounds;
  allocating five percent to each side gives a 90% union-bound target.
- Row-coverage and simultaneous-group gates must both remain visible because
  exact cluster intervals can be intentionally conservative rowwise.
