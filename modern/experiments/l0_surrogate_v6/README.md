# L0 surrogate v6

V6 is a prospective validation of a changed protocol informed openly by the
failed V5 outcomes. It is not an ahistorical independent confirmation.

One global candidate role, one method-selection role, one final-calibration
role and one single-use assessment role are group and coordinate disjoint.
The assessment coordinates do not occur in any V3–V5 held-out set. All roles
remain within the same L0 input domain, so coarse spatial-domain overlap is
intentional and disclosed.

Budgets 96, 128 and 160 are evaluated using method-selection labels only. The
smallest budget passing every method point and group-stability gate is frozen.
If none passes, execution stops without opening final calibration or
assessment labels. Final intervals use equal-group-weight conformal ranks.

Execution is permitted once from a clean detached preregistration commit with
an actual-import Git-blob closure and retained atomic lock.
