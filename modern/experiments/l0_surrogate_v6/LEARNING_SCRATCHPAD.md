# L0 surrogate v6 learning scratchpad

- V5 is development evidence for V6, so prospective validation must disclose
  the protocol change rather than claim historical independence.
- A single globally untouched assessment avoids presenting correlated
  cross-replicate folds as independent confirmations.
- Freezing method selection before final calibration creates a testable label
  access boundary.
- Runtime provenance is strongest when derived from actual imported module
  paths and matched to committed Git blobs, including package initializers.
