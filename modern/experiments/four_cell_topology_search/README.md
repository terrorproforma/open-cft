# Four-cell topology-targeted search

Version 1 preserves 128 deterministic shifted-Halton designs evaluated through
accepted geometry v1.1, the L1a Warp field model, coupling v2, and four-cell
global-plasma screening equations.

This is development evidence only. The protocol was not preregistered, coupling
v2 used a deprecated same-z mirror proxy, and selected null lows are
roundoff-scale. Consequently, no v1 mirror ratio/probability is a physical
mirror claim, and its six rank-22/25 roots are non-identifiable
screening-equation residual roots—not plasma-state or performance publications.

From `modern/`:

```powershell
$env:PYTHONPATH="$PWD\src;$PWD"
python -m experiments.four_cell_topology_search.run
```

The preserved development gates are recorded in `experiment.py`. They are not
retroactively described as preregistered gates.

The metadata-only v1.0.1 correction did not rerun simulations, change numerical
values, or alter selection/ranking. Outcome objects retain residual,
conservation-closure, and rank diagnostics only. Removed state vectors and
power evaluations remain in a top-level audit-only raw-data archive with
publication prohibited.

`results/dataset.json`, `results/manifest.json`, `results/report.md`, and the
representative full fields/geometries are deterministic and SHA-256 sealed.
No runtime benchmark or performance output is published. Coupling v3 and a
preregistered topology search v2 are both required before physical mirror,
identifiable-state, or performance claims.
